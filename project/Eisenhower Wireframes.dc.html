Editing stays live even while focused. Built on 2a’s look; Done list has no origin tag.

2Plan / Do model — built on 1a

Keeping 1a’s monochrome, weight-based look. Two tabs at the very top: Plan (add / move / edit / delete — the full editing canvas) and Do (enter focus and just complete tasks). In Do mode the matrix steps through quadrants in priority order — Do First → Schedule → Delegate → Eliminate — one quadrant lit at a time, the rest faded, advancing only when the active one is cleared. Done list drops the origin tag. Two takes on how literal “one at a time” feels: 2b (active quadrant) vs 2c (single card).

2aPlan mode — the editing canvas

Default tab. Everything is editable: add a task right inside its quadrant via the inline ＋ row, drag cards between quadrants, hover a card for edit/delete. This is the only place structure changes.
